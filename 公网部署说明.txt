HGhub 公网部署说明（Vercel）

项目类型：Vite + React 静态网站
构建命令：pnpm build
输出目录：dist
安装命令：pnpm install --frozen-lockfile

发布步骤：
1. 注册/登录 GitHub：https://github.com/signup
2. 在 GitHub 创建一个 New repository，名称可填 HGhub-web。
3. 解压本项目 ZIP，把 HGhub-web 文件夹里的全部项目文件上传到仓库根目录（不要把外层 HGhub-web 文件夹再套一层）。
4. 打开 https://vercel.com/signup 注册/登录 Vercel。可以选择使用 GitHub 登录。
5. 打开 https://vercel.com/new，选择刚才的 HGhub-web 仓库并 Import。
6. 检查 Framework Preset 为 Vite，Build Command 为 pnpm build，Output Directory 为 dist；Install Command 为 pnpm install --frozen-lockfile。
7. 点击 Deploy，等待构建完成。Vercel 会分配一个公开的 https://xxxx.vercel.app 网址。
8. 把该网址发给访客即可公开访问。以后更新 GitHub 仓库，Vercel 会自动重新部署。

重要提醒：
- 当前只配置了静态前端部署；本地开发服务器不会变成线上服务器。
- 如果项目将来需要数据库、账号登录、后台管理或真实 API，还需要单独配置后端服务。
- 本项目 package.json 标注 PolyForm Noncommercial 1.0.0；公开访问不等于获得商业使用授权。商业用途前请先确认许可证条款。
- 部署前请检查页面内容及素材是否有公开发布权限，不要上传密钥、密码或个人资料。
